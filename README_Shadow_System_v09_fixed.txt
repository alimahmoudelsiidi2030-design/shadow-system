نظام الظل v09 — تعليمات النسخة المصححة

الفتح والاستخدام المحلي
1. فك ضغط Shadow_System_v09_fixed_PWA.zip.
2. افتح Shadow_System_v09_fixed.html في متصفح حديث.
3. تُحفظ البيانات على الجهاز داخل المتصفح نفسه. استخدم التصدير من إعدادات التطبيق للاحتفاظ بنسخة احتياطية.

التثبيت كتطبيق ويب PWA
1. ارفع جميع ملفات الحزمة إلى المجلد نفسه على استضافة HTTPS، أو شغّلها عبر localhost.
2. افتح Shadow_System_v09_fixed.html مرة واحدة مع اتصال بالإنترنت، وانتظر اكتمال التحميل.
3. استخدم خيار «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية» من قائمة المتصفح؛ تختلف تسمية الخيار حسب المتصفح والجهاز.
4. بعد ذلك يمكن للمتصفح استخدام موارد واجهة التطبيق الأساسية المخزنة مؤقتًا دون اتصال.

ملاحظات مهمة
- فتح ملف HTML مباشرةً يعمل محليًا، لكنه لا يتيح تثبيت PWA أو تسجيل Service Worker.
- يجب أن تبقى ملفات HTML وmanifest وService Worker والأيقونات في المجلد نفسه.
- البيانات محلية ولا توجد مزامنة سحابية بين الأجهزة أو المتصفحات.
- الخطوط وميزات الذكاء الاصطناعي أو الصوت الخارجية قد تحتاج اتصالًا بالإنترنت.
- لم يُختبر مربع التثبيت على هاتف فعلي؛ الاختبار شمل Chromium محليًا وموارد التخزين دون اتصال.
